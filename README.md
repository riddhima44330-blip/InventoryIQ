
# InventoryIQ – Product Inventory & Analytics Dashboard

InventoryIQ is an interactive, browser-based inventory management dashboard built using HTML, CSS, and JavaScript. It helps users manage products, organize inventory, and analyze product data through dynamic calculations and visual summaries.

## ✨ Features

- **Product Management:** Add, edit, and delete products.
- **Search & Filtering:** Search for products and filter them by category.
- **Sorting:** Organize products based on available sorting options.
- **Automatic Categorization:** Classify products into Budget, Standard, and Premium categories based on price.
- **Inventory Analytics:** Calculate total inventory value and display category-wise breakdowns.
- **Tax & Discount Calculator:** Calculate inventory value with tax and discounts.
- **Affordable Products:** Identify products priced below $200.
- **Inventory Report:** Generate a formatted inventory report and copy it to the clipboard.
- **Input Validation:** Validate product details and prevent duplicate entries.
- **Interactive Interface:** Manage inventory through a responsive dashboard.

## 🛠️ Technologies Used

- HTML5 – Page structure
- CSS3 – Styling and layout
- JavaScript (ES6+) – Application logic, data processing, and interactivity

## 🚀 Getting Started

### Prerequisites

A modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/riddhima44330-blip/InventoryIQ.git
   ```

2. Navigate to the project folder:

   ```bash
   cd InventoryIQ
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

## 📊 Calculations

The dashboard demonstrates inventory calculations using:

- **Inventory Value:** Sum of all product prices
- **Tax-Included Value:** Inventory value plus 18% tax
- **Discounted Value:** Inventory value after a 10% discount
- **Affordable Products:** Products priced below $200
